\label{sec:results:rsim}

Ideal kinematics is the primary comparator because it isolates what the
identified dynamics contribute: both plants run in the same harness, start from
the same measured body velocity, and are scored on the same windows, so the
model is the only difference. Its median position error is lower at every
horizon (Fig.~\ref{fig:main}, Table~\ref{tab:three}): $\SI{0.039}{m}$ against
$\SI{0.101}{m}$ at $h_{\mathrm{ref}}$, and $\SI{0.119}{m}$ against
$\SI{0.291}{m}$ at $\SI{1.5}{s}$. For scale, the median commanded speed over
these windows is about $\SI{1}{m/s}$, so $h_{\mathrm{ref}}$ spans roughly
$\SI{0.4}{m}$ of travel against a robot contact diameter of $\SI{0.16}{m}$.

The scored population is $264$ dense windows, $49$ of them non-overlapping,
amounting at $H_{\max}$ to $\SI{73.5}{s}$ of motion from ten hold-out events.
Windows from one event share robot, surface, session and controller, so we take
the \emph{event} as the unit of analysis. Pairing event medians, the model wins
all ten; the median of the per-event differences is $+\SI{0.069}{m}$, with a
bootstrap interval over events of $[+0.038,+0.097]\,\si{m}$ and a one-sided
Wilcoxon $p = 9.8\times10^{-4}$, the smallest value attainable at $n=10$. The
pre-registered window-level test agrees ($+\SI{0.054}{m}$,
$p = 1.2\times10^{-8}$, effect $+0.633$); we lead with the event figure because
windows within an event are not independent, and it is the conservative of the
two. All four gate conditions hold under either unit.

The ten events are exactly the frozen hold-out list, and none contributed to
any fit: the five that validated $v_x$ and $v_y$ are a subset of them, and the
other five carry a motion label (\texttt{shoot\_to\_goal}) that entered neither
fit.
